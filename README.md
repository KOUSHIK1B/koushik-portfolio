# Koushik Bodasu — Python Full-Stack Portfolio

A responsive single-page portfolio built with:
- HTML5
- CSS3
- Vanilla JavaScript

## Run locally
Open `index.html` in a browser.

## Deploy free
You can publish this on GitHub Pages:
1. Create a GitHub repository named `koushik-portfolio`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to Settings → Pages.
4. Select the main branch and root folder.
5. Save and open the generated GitHub Pages URL.

## Before publishing
- Replace any project links with your real GitHub repositories/demo URLs.
- Keep only projects you can explain confidently in an interview.
- Add a profile photo only if you want one.
